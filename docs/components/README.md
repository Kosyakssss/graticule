# Components

One page per component: what it is for, how app code makes it, how it behaves from the keyboard and what a screen reader says. Specimen shows each page next to the live component (Components, then the component's name).

The components the kernel has today: [page](page.md), [row](row.md), [columns](columns.md), [text](text.md), [button](button.md), [link](link.md), [check](check.md), [field](field.md), [list](list.md), [empty](empty.md), and the window's own lines, which every app gets: the [action bar](bar.md), the [status line](status.md), the [message line](message.md) and the [palette](palette.md).
