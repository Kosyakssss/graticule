# Action bar

Every command available right now, at the bottom of every window, generated from the app's registry, with each command's keys in front of it. A command that can't run is drawn faint, and hovering it puts why in the status line. Undo, Redo and the palette are always there. After the first key of a sequence, the bar shows what can come next instead.

## Code

None: the kernel draws it for every app.

## Keys

Its commands' own keys, from the keymap and the platform.

## Screen reader

A toolbar of buttons, each with its label and keys.
