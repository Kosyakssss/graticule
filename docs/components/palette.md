# Palette

Every command, found by typing. It opens over the page with the palette command, lists every command the app has with its keys, narrows as you type, and runs the highlighted one with Return; one that can't run says why. With several items chosen, a command that takes many says how many ("Remove 4 items").

## Code

None: the kernel draws it for every app.

## Keys

The palette command opens it, the arrows move the highlight, Return runs it, Escape closes it.

## Screen reader

A dialog with a text field and a list of options.
