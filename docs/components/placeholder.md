# Placeholder

Rows kept for content that hasn't arrived yet, drawn as faint lines of different lengths. When the content comes, it takes the same rows, so nothing on the page jumps.

## Use it for

What a page shows in the moment before data that arrives late, such as an article fetched from the network. Show it only for as long as nothing is there: once the data comes, the placeholder is gone, and while it is missing the status line says what is being fetched.

## Code

```rust
ui.placeholder(3);
```

## Screen reader

"Loading".
