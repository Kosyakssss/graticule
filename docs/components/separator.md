# Separator

A rule between what comes before it and what comes after, drawn on a cell edge with the same room above and below.

## Use it for

Parting groups on a page that belong to different things, when a heading would say too much.

## Code

```rust
ui.text("Above the rule");
ui.separator();
ui.text("Below the rule");
```

## Screen reader

Nothing: the rule only shows what the structure already says.
