# Swatch

A small box filled with one of the theme's inks: a label's color, a series in a legend, a choice of color. The ink is named, not mixed, so the swatch follows the theme and the appearance like everything else.

## Use it for

Showing which color stands for what. Every ink is shown this way in Specimen's Style place.

## Code

```rust
ui.swatch(Ink::Danger);
```

## Screen reader

An image, named after its ink ("danger").
